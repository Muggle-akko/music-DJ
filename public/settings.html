连接电脑上的 Agent

下载此实例的连接文件，在电脑上配置 Awudio MCP。Agent 创作后，电台会出现在所有设备的电台库里。

连接文件包含控制凭证，请保存在私有目录，不要提交到 Git。Mac 关闭后，已保存的电台仍可收听。

电脑端配置方法
AWUDIO_BRIDGE_FILE=/私有目录/awudio-remote.json npm run mcp

把上述环境变量与项目 scripts/awudio-mcp.mjs 配置到 Agent 客户端。完整步骤见仓库 md/server-deployment.md。

资料备份

保存电台、偏好与收藏资料到这台设备，不包含音频和登录凭据。

本机缓存

最近一首歌曲、封面、页面资源和近期列表保存在此浏览器，清理后需要重新加载。不会退出网易云或删除云端资料。
