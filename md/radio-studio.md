# 电台制作与历史回听

## 产品流程

选歌与制作电台是两个独立动作。普通推荐只展示歌曲；用户点击“制作电台”，或明确要求 Agent 制作时，才建立电台草稿。建立、写稿、保存均不替换队列、不开始播放。

入口：

- 外部 Agent 推荐歌单下的“制作电台”：按该歌单的曲序建立草稿，不要求先把歌单放进队列。推荐计划的短期播放资格过期不影响编辑资料；回听仍由播放接口检查实时资格。
- 队列上方的“制作电台”：以当前已同步队列的版本建立草稿，支持内置推荐、搜索、收藏或手动整理后的网易云歌曲。
- 历史电台的“编辑”：以原电台建立修订草稿，保存时更新原电台。不同草稿修改同一期时检查历史版本，防止后保存的旧页覆盖新稿。

每期 1–30 首，最多 12 段解说；默认约 38% 覆盖、通常至少 3 段（小歌单以曲目数为限），可改为少说约 20% 或多聊约 60%。分散到首、中、尾，不要求每首都说。开场和结语是文案角色，实际出现位置可以是歌曲前奏、间奏、尾奏的歌词空档候选。每首最多一段、最多 600 字，可修改、清空或手动设置出现秒数。草稿的曲序固定，修改选曲后重新建立草稿。

## 两种写稿方式

API 生成沿用已配置的文本模型，输入本期标题、用户要求、曲目、专辑、选曲理由、内容偏好、歌词空档候选及筛选后的相关热评。歌词/评论查询最多 4 路并发、总计约 8 秒预算，缺失不阻塞制作；热评不含用户身份，仅作主观线索转述，不当作事实。恢复 Faye 的亲近口吻、背景/听感/陪伴/文化联想等多角度交替，以及模板套话和重复长句过滤。只写解说，不重新选歌。输出经真实 trackId、位置、长度、频率、唯一性检查后写入草稿。生成失败保留原稿；生成期间被其他页面或 Agent 修改时拒绝覆盖。

Agent 来写：复制制作任务到当前 Agent，Agent 读取最新草稿，自己撰写并提交；不经过内置模型 API。网页点击“读取最新草稿”后审阅。生成方式不影响后续编辑和归档格式。

已有内置推荐在用户明确要求解说时，也会使用同一套生成和校验逻辑，不再拼接固定一句开场。未配置模型或生成失败时明确提示，可通过制作入口继续。

写稿不等于配音。“回听时朗读解说”独立控制：有 Fish Audio 配置才可启用；否则保存文字解说，在设定时间于播放器主播区显示。两句歌词时间戳间隔超过 12 秒后扣除两侧余量，再检查可容纳文案的窗口。歌词空档是启发式信号，不能宣称无人声；没有足够窗口或文案太长时保留文字，不强插语音。语音抵达窗口结束时间会停止并恢复音乐音量，避免合成时长超出估算后持续覆盖后续歌词。沿用已有缓存、压低音乐音量和恢复机制；合成失败不应打断音乐。没有引入浏览器系统朗读或新语音供应商。

## 保存与回听

草稿按账号保存在本地状态，最多 20 份；达到上限时优先回收最旧的已完整保存草稿，未完成草稿不自动丢弃。“继续制作”可切换草稿，刷新文案前应注意本页未保存修改。

保存为历史电台时存储标题、固定曲序、解说全文、解说来源、朗读开关和歌曲元数据。音频使用本地代理路径，避免旧的签名链接失效。历史最多 40 期，与已有历史电台兼容。同一草稿重复保存更新同一期；重试相同 operationId 不产生重复记录。

“载入”会替换当前队列、切为列表循环并保持暂停；用户点击播放后才回听。保存不是云端网易云歌单写入，不会修改网易云红心。

## Agent 契约

- `awudio_prepare_radio`：`source=queue` 带最新 `expectedQueueRevision`；`source=plan/history` 带 `sourceId`，返回持久草稿。
- `awudio_get_radio`：无参数列出草稿及历史摘要；带 `draftId` 读取完整曲序、解说和 `revision`。
- `awudio_write_radio_script`：带 `draftId`、`expectedRevision`、唯一 `operationId`；`mode=api` 调用 API，`mode=agent` 提交 `cues: [{trackId,kind,text}]`。网页手动编辑使用 `manual`。
- `awudio_save_radio`：带最新草稿版本、标题和 `narration` 保存。该工具不播放；实际播放继续遵守现有播放授权和回执契约。

上述写操作的结果可用原有 `awudio_get_operation` 查询。遇到超时先查询同一操作，不盲目创建另一份草稿。Agent 不应将“写稿”推断为“保存并播放”。

新增工具后客户端需重新加载 MCP 工具列表；API 写稿调用最长约 90 秒，示例配置将 MCP 工具超时设为 120 秒。

## 本轮验证边界

单元测试覆盖 API/Agent 共稿、持久恢复、重复保存、草稿和历史的版本冲突、无模型/无语音配置、解说 ID/位置校验以及队列不变。

HTTP 回归验证经过真实服务路由及状态规范化后，解说、版本号和历史电台仍保留。界面检查使用独立临时目录、模拟网易云和模拟文本模型，不代表真实模型文案质量或 Fish Audio 配音验收。没有替换真实队列或触发真实音乐播放。
