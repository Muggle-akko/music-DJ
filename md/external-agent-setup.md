# 外部 Agent 模式：首版接入说明

状态更新（2026-10-16）：已配置本机 Codex，完成 MCP 握手与真实曲库歌单推荐。新增电台制作的自动化与界面检查使用隔离模拟数据，尚未进行真实解说 API、语音合成和连续播放验收。首版交付时未验收的记录保留在下文，当前验证边界见 [电台制作说明](radio-studio.md)。

## 1. 启动音乐服务

需要 Node 22+。在项目根目录执行 `npm install`（依赖已有时无需重复）和 `npm run dev`，并按原配置启动本地网易云适配服务。

网页为 <http://localhost:4173/>。服务启动时自动建立忽略目录中的 `data/agent-bridge.json`，权限 0600；MCP 进程自动读取，不需要向聊天窗口复制凭证。自定义 `AWUDIO_DATA_DIR` 时，主服务和 MCP 必须使用相同目录。

打开“AI 电台”，将“选歌方式”切为“外部 Agent”。多个网页打开时选择接收控制的播放页面。

## 2. 连接 Codex

配置示例位于 [config/awudio-mcp.example.toml](../config/awudio-mcp.example.toml)。将其中的服务表合并到当前客户端实际使用的配置，优先项目范围 `.codex/config.toml`；项目需要被客户端信任。不要覆盖已有配置表。

示例的 Node 和项目路径针对当前电脑，迁移项目后修改。也可以在客户端支持的 MCP 设置页中以 STDIO 方式填入相同 command 和 args。

可选 CLI 方式（会写入 CLI 使用的 MCP 配置）：

```sh
codex mcp add awudio -- /Users/awu/.local/share/fnm/node-versions/v24.15.0/installation/bin/node /Users/awu/Documents/ChatGPT/musicdj/scripts/awudio-mcp.mjs
```

修改后按客户端要求重载 MCP/重新开启会话。应能发现以 `awudio_` 开头的 17 个工具（13 个选歌/播放工具、4 个电台制作工具）；客户端可能再给工具增加服务名前缀。API 写稿最长约 90 秒，MCP 工具超时建议设为 120 秒。网页的连接状态在第一次音乐工具调用后更新，不代表 Agent 正在思考或可被网页唤醒。

首版只提供了配置示例；后续已按用户要求注册本机 Codex 配置并完成连接。WorkBuddy 未联调，不能宣称已经兼容；若支持 STDIO MCP，可使用同一入口再单独验收。

## 3. 使用音乐 Skill

项目内 Skill 在 [skills/awudio/SKILL.md](../skills/awudio/SKILL.md)。当前会话可直接指明使用此文件。需要自动发现时，将整个 `awudio` 目录安装到客户端支持的项目或用户 Skill 目录；本轮不改全局 Skill 目录。

示例请求：

- “使用项目里的 Awudio Skill，推荐英国乐队 boa 的三首歌，先别放。”
- “播放刚才那三首。”
- “这首不打断，再找几首类似的放到后面。”

外部 Agent 自己进行检索、选择与对话。本地工具不会再次调用内置 DeepSeek/OpenAI 推荐器。外部客户端的模型费用与额度依然由该客户端决定。

## 4. 结果与故障状态

- “已展示”只表示计划已出现在网页；队列可能尚未改变。
- “队列已更新”不代表实际发声；开始播放以浏览器 playing 回执为准。
- 应用计划并开始播放时切为列表循环，确保后续歌曲可由播放器自动接续；普通继续播放保持当前循环设置。
- 浏览器阻止自动播放时会出现“点击开始播放”。
- 队列冲突时，本页编辑保留；选择使用最新队列或明确保留本页编辑，避免自动覆盖。
- 页面离线不积压日后自动播放的请求；过期命令不补执行。
- uncertain 表示可能执行但未确认，先查询实际状态，尤其不能重复下一首。
- 退出外部模式后待执行指令失效，已有队列仍由播放器继续管理。

停用时在网页切回内置推荐，并在客户端禁用/移除 `awudio` MCP 配置。无需删除收藏、反馈或播放历史。
