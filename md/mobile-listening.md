# 移动收听端（2026-10-16）

移动端以收听为主：原生播放器在上，播放队列紧随其后；下面是一张固定高度的双面卡片：正面为播放队列、我喜欢、历史电台，背面为 AI 推荐、搜索、云歌单。只有翻面按钮改变卡片正反面；切换标签保留各自状态，列表在卡片内部滚动。解说框保留在播放器中，日期、星期、距离周末同时显示；天气需浏览器位置权限且请求成功，否则不显示。网易云登录、设备命名、Agent 控制目标和收藏同步集中在齿轮设置底部面板。手机和 iPad 隐藏内置模型推荐、制作/编辑电台及生成解说入口；电脑仍保留制作工具。

移动浏览器注册后默认选择 Agent 模式。浏览器内置推荐和电台制作请求同时在后端按移动客户端标记/UA 拒绝；Agent 的 Bearer 接口继续供电脑端使用。这是单实例所有者的设备工作流划分，并非独立的用户权限角色或不可伪造的设备认证。现有单一播放目标与设备独立队列规则不变。

手机/iPad 不再把主音频接到 Web Audio 分析器中，音频由原生 HTMLAudioElement 输出；波形以独立 OfflineAudioContext 解码得到的真实音量包络随播放时间变化，并响应音量和静音。首次分析需要额外下载当前音频（上限 12MB），只在前台发起，最多缓存两首的包络；不支持、超限或分析失败时使用静态细条，不再使用正弦假动画。桌面继续使用实时频谱；设置可用的 audioSession 为 playback。等待缓冲时同步页面和 Media Session 状态，网络 stalled 但缓冲尚足时不误报暂停；出错后点击一次播放可刷新音源并恢复位置。未加入静音保活或强行自动播放。WebKit 对 AudioContext 后台中断有历史问题记录：https://bugs.webkit.org/show_bug.cgi?id=261554 。这不能替代当前 iOS 版本的实机测试。

已检查 390px 隔离页面的六个标签、翻面、解说框和日期。各标签和正反面实测卡片总高度均为 598px；使用独立临时资料和 24 首测试曲目，没有修改用户队列。122 项测试通过、1 项 PostgreSQL 跨实例测试因本轮未配置测试数据库而跳过。包含移动 API 限制、iPad 桌面 UA 检测、缓冲状态、波形强弱/静音/分析失败与并发切歌回归。

真机待验：Safari 和主屏幕 Web App 分别手动播放，锁屏持续收听，后台跨曲，锁屏播放/暂停/上一首/下一首，以及电台解说与音乐衔接。浏览器或系统可暂停页面或限制媒体；本轮不将桌面布局预览视作 iPhone 后台播放验收。

## 推荐与共享实例（2026-10-16）

Agent 推荐按创建时间保留 3 天，访问快照时清理旧结果，不影响已保存的历史电台。单曲复用搜索列表操作：立即播放会定位已有歌曲；未在队列中时插到队首后播放；加入按钮追加队尾并去重。云歌单不显示推荐反馈菜单。390px 移动端双面卡片总高 798px，列表内部滚动，切标签保持尺寸。

访问密码授权整个单一所有者实例，不是访客只读权限。浏览器共同使用服务器中已验证的网易云账号，不传回原始 Cookie；失效后可在设置重新扫码或填写原账号 Cookie。推荐、电台、收藏反馈和账号连接共享，设备队列与进度独立。播放设备选择仅用于 Agent 的播放控制指令，推荐结果不会因未选中而隐藏。
